# Сертификаты преподавателей

## Маршруты

- `/certificates/:token` — публичная карточка без AuthProvider и авторизации; имя, фото, образование, описание, сады и QR.
- `/my-certificate` — собственный сертификат пользователя TEACHER, ссылка и PDF.
- `/teacher-certificates` — управление OWNER: список, создание, редактор, фото, публикация, отзыв, PDF и ZIP.
- В таблице преподавателей действие «Сертификат» открывает существующий документ или форму создания.

Публичные запросы выполняются отдельным клиентом без bearer и auth redirect interceptor. Протухшая сохранённая сессия не мешает публичному маршруту. Медиа закрытых экранов загружаются с авторизацией в Blob URL; токен не передаётся в URL. Приватные действия всегда подтверждаются сервером по роли и текущей версии документа.

## Настройка

`REACT_APP_API_BASE_URL` указывает на backend API. При локальной проверке его необходимо задавать явно: дефолт проекта ведёт на продуктивный API.

Backend должен иметь `PUBLIC_CERTIFICATE_BASE_URL`, содержащий origin frontend без префикса пути. Ссылку предоставляет сервер; frontend не вычисляет замену из адреса посетителя. При отсутствии настройки ссылка недоступна и интерфейс сообщает об этом.

Для прямых ссылок настроить SPA fallback на `index.html`. Приложение размещается в корне домена. Авторизация на web-хостинге не должна закрывать `/certificates/:token`.

## Проверка

```sh
CI=true REACT_APP_API_BASE_URL=http://127.0.0.1:5027/api npm test -- --watchAll=false --runInBand
REACT_APP_API_BASE_URL=http://127.0.0.1:5027/api npm run build
```

Тесты сертификатов проверяют реальные границы маршрутов и AuthProvider, роли, публичные состояния, сохранение и загрузку фото с revision, повторный выбор файла после конфликта, отсутствие канонической ссылки и формирование запросов PDF/ZIP. Production-базу для тестов использовать нельзя.

## Публикация

Перед выпуском frontend применить backend migration `20261008_001_teacher_certificates.sql`, установить backend dependencies и настроить публичный origin. Продуктивное применение, коммиты и push выполняются только по отдельной команде пользователя.
